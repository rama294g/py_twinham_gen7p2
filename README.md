# TwinHAM v7.2 マイコンソフトウェア

TwinHAM は、手動車椅子を電動化するためのポン付けユニットです。本リポジトリには、**TwinHAM バージョン 7.2** の制御マイコン（Raspberry Pi Pico 2 W）で動作する MicroPython ソフトウェアを収録しています。

> [!WARNING]
> 本ソフトウェアはモーターを駆動します。車椅子に搭載する前に、車輪を浮かせるなどして無負荷・低出力で十分に動作確認してください。非常停止手段を確保し、配線、回転方向、ゼロ点、角度および PWM の設定を確認してから使用してください。

## 主な機能

- BNO055 の加速度・ジャイロデータから車体角度を推定
- 推定角度に応じた CW / CCW モーター PWM 制御
- ゼロスイッチによる基準角度設定と押下中のみのモーター駆動
- 8 文字 × 2 行 I2C LCD への状態表示
- 5 方向ジョイスティックによる表示・制御パラメーター設定
- センサー異常、通信タイムアウト、メニュー操作中のモーター停止
- `config.json` への設定保存（ファイルは初回保存時に自動生成）

## 対象環境

| 項目 | 内容 |
| --- | --- |
| マイコン | Raspberry Pi Pico 2 W |
| 実行環境 | MicroPython |
| エントリーポイント | `main.py` |
| 姿勢センサー | BNO055（UART、115200 bps、NDOF モード） |
| LCD | I2C、アドレス `0x3E`、8 文字 × 2 行 |
| モーター PWM 周波数 | 5 kHz |
| センサー・制御周期 | 20 ms（50 Hz） |

外部 Python パッケージは使用していません。`machine`、`uasyncio` など、MicroPython ファームウェアに含まれるモジュールを使用します。

## ピンアサイン

| GPIO | 用途 | 備考 |
| --- | --- | --- |
| GP0 | LCD SDA | I2C0 |
| GP1 | LCD SCL | I2C0 |
| GP4 | BNO055 UART TX | UART1、Pico から BNO055 へ接続 |
| GP5 | BNO055 UART RX | UART1、BNO055 から Pico へ接続 |
| GP6 | ゼロ／運転スイッチ | Active Low、内部プルアップ。押下中のみ運転 |
| GP16 | モータードライバー CW PWM | 5 kHz |
| GP17 | モータードライバー CCW PWM | 5 kHz |
| GP18 | モータードライバー nSLEEP | Low でスリープ |
| GP26 | 5 方向ジョイスティック | ADC 入力 |

各機器の GND は共通にしてください。BNO055 の UART は、BNO055 側の TX を Pico の GP5（RX）へ、BNO055 側の RX を Pico の GP4（TX）へ交差接続します。使用するモータードライバーや周辺機器の電圧・電流仕様は、それぞれのデータシートに従ってください。

## セットアップ

### 1. MicroPython の準備

Raspberry Pi Pico 2 W に対応する MicroPython ファームウェアをマイコンへ書き込みます。ファームウェアの書き込み方法は MicroPython または Raspberry Pi の公式手順を参照してください。

### 2. プログラムファイルの転送

USB で Pico 2 W を PC に接続し、`main.py` と同じ階層にある全ての `.py` ファイルをマイコンのルートへコピーします。たとえば `mpremote` を使用する場合は、リポジトリのルートで次を実行します。

```bash
for file in *.py; do mpremote connect auto fs cp "$file" ":$file"; done
```

転送後、Pico 2 W を再起動します。

```bash
mpremote connect auto reset
```

シリアル出力を確認する場合は、次を実行します。

```bash
mpremote connect auto repl
```

## 起動と基本操作

1. 初期状態ではモータードライバーはスリープします。
2. 起動時に LCD と BNO055 を初期化します。
3. BNO055 を認識できない場合は LCD に `BNO ERR` / `CHECK` と表示し、モーターを停止したまま待機します。配線と UART 設定を確認してください。
4. 正常起動後、GP6 のスイッチを一度押して現在姿勢をゼロ点として設定します。
5. GP6 を押している間だけモーターが有効になります。離すと直ちにモータードライバーがスリープします。

起動直後はゼロ点が未設定のため、GP6 を押すまでモーターは動作しません。ゼロ点設定後も、センサーが正常でない場合やメニューを表示している場合はモーターを停止します。

## ジョイスティックメニュー

通常画面でジョイスティックの中央を押すとメニューを開きます。

- **UP / DOWN**: 項目の移動、編集値を 1 ずつ変更
- **RIGHT / LEFT**: 編集値を 5 ずつ変更
- **CENTER**: 決定・保存
- **LEFT**: 編集またはメニューから戻る（通常のメニュー画面）

メニューでは次の項目を設定できます。

- `GAIN`: 制御ゲイン
- `NEUTRAL`: 基準角度
- `PWM_MAX` / `PWM_MIN`: 正転・逆転の最大 PWM 指令値
- `ANG_MAX` / `ANG_MIN`: PWM へ割り当てる正負の角度範囲
- `SW_SIDE`: スイッチの取付側（`LEFT` / `RIGHT`）
- `RESET`: PWM、角度範囲、LCD 表示項目を初期値へ戻す
- `DISPLAY`: LCD の 1 行目と 2 行目に表示する情報を選択

LCD には角度、PWM、センサー状態、スイッチ状態、ゼロ点、ジョイスティック、各フィルター段の角度、ジャイロ値、累積エラー数を選択して表示できます。

## 設定値

設定は Pico 2 W 上の `config.json` に保存され、次回起動時に読み込まれます。

| 設定 | 初期値 | 設定可能範囲 |
| --- | ---: | ---: |
| `GAIN` | `50` | `0` ～ `100` |
| `NEUTRAL` | `30` | `10` ～ `50` 度 |
| `PWM_MAX` | `30` | `1` ～ `100` |
| `PWM_MIN` | `-30` | `-100` ～ `-1` |
| `ANGLE_MAX` | `90` | `1` ～ `180` 度 |
| `ANGLE_MIN` | `-90` | `-180` ～ `-1` 度 |
| `SW_IS_RIGHT` | `false` (`LEFT`) | `LEFT` / `RIGHT` |

`config.json` が存在しない、読み込めない、または値が不正な場合は初期値を使用します。設定ファイルを削除すると、次回起動時は初期値で動作します。

## Bluetooth LE 通信

Pico 2 W は `TwinHAM_LH` という名前で Advertising し、Nordic UART Service
互換の RX Characteristic で UTF-8 コマンドを受け付けます。コマンドは改行で
区切ることができ、応答と定期送信データは改行で終端されます。

| コマンド | 動作 |
| --- | --- |
| `SET,GAIN,<値>` | `GAIN` を `0` ～ `100` の範囲で変更 |
| `SET,NEUTRAL,<値>` | `NEUTRAL` を `10` ～ `50` 度の範囲で変更 |
| `GET,CONFIG` | 現在の全設定を取得 |
| `GET,STATUS` | 現在角度、操作入力、モーター、センサー状態を取得 |
| `SAVE` | 変更した設定を `config.json` に保存 |
| `MOTOR,STOP` | BLE からの再許可までモーターを停止 |
| `MOTOR,ENABLE` | モーター駆動を再許可（実際の駆動には通常の安全条件も必要） |
| `PING` | `PONG` を返す |

`SET` の応答には範囲補正後に実際に適用された値が含まれます。設定を再起動後も
保持するには、変更後に `SAVE` を送信してください。Bluetooth からの
`MOTOR,ENABLE` はゼロ点設定、物理スイッチ、センサー正常性などの安全条件を
迂回しません。

## 安全機能と注意事項

- 電源投入時はモータードライバーをスリープ状態にします。
- 起動後にゼロ点を設定するまでモーターを有効にしません。
- GP6 のスイッチを押している間だけモーターを駆動します。
- センサー通信が 500 ms を超えて途絶えた場合はモーターを停止します。
- 一時的な UART 読み取りエラーでは最後の有効な角度を保持し、タイムアウト後に停止します。
- BNO055 の送受信は UART の RX-idle / TX-idle 割り込み callback で処理し、各 256 byte の固定リングバッファを使用します。
- メニュー操作中、BNO055 初期化失敗時、制御処理の例外発生時はモーターを停止します。
- PWM 指令の絶対値が `3` 未満の場合はデッドバンドとして停止します。

これらは補助的なソフトウェア機能であり、独立した非常停止回路、過電流保護、機械的な制動装置などのハードウェア安全対策を代替するものではありません。実際の車椅子で使用する場合は、関係法令・規格を確認し、十分なリスク評価と検証を行ってください。

## リポジトリ構成

```text
.
├── main.py          # アクチュエーションと composition root
├── app_state.py     # 共通設定、実行時状態、純粋な補助関数
├── bno055.py        # BNO055 UART 通信
├── sensing.py       # センシング、角度推定
├── lcd_menu.py      # LCD、ジョイスティックメニュー
├── config_store.py  # config.json の保存と読み込み
└── README.md        # 本ドキュメント
```

`main.py` はアクチュエーションと安全停止を担当し、その他の機能モジュールを組み立てる composition root として機能します。

## 開発時の確認

`main.py` は Pico 2 W のハードウェア API を起動時に使用するため、通常の CPython では実行できません。構文のみを確認する場合は、次のように実行できます。

```bash
python -m py_compile *.py
```

実機確認では、最低限次の項目を確認してください。

1. 起動直後および GP6 解放時にモーターが停止すること
2. BNO055 の切断または通信異常時にモーターが停止すること
3. ゼロ点で角度と PWM がほぼ 0 になること
4. 車体の傾きと CW / CCW の回転方向が一致すること
5. LCD とジョイスティックからの設定が再起動後も保持されること
